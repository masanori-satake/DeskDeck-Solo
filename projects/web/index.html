Chrome Extension for Chromebook Tablet Mode

Chromebookのサイドパネルに再現する
大型タッチ仮想ハードウェアデッキ

外部ライブラリ・外部通信を一切使わず完全ローカルで動作。 大型回転ノブ、トグルスイッチ、大判タッチボタンでChromebookのタブレット操作を物理コントローラーのように最適化します。

⚡

完全ローカル・依存なし

WebpackやReact等のビルドツール・フレームワークを使わない Pure Vanilla JavaScript / HTML5 / CSS3 構成。

👆

大型タッチターゲット

Pointer Events を使用した大型回転ノブやトグルスイッチを搭載。Chromebookのタッチパネルで快適にドラッグ操作が可能。

🔒

プライバシー＆セキュリティ

外部サーバー通信やアナリティクスを一切含まないManifest V3準拠の完全スタンドアロン構造。
