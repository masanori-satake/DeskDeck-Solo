DeskDeck-Solo Quickstart Guide

Installation Steps

  1. Download and extract DeskDeck-Solo-v0.1.0.zip or clone the repository.
  2. Open chrome://extensions/ in Chrome and enable "Developer mode".
  3. Click "Load unpacked" and select the projects/app folder.
  4. Open Side Panel in Chrome and select DeskDeck-Solo.

Presets

Use Media, Meeting, Reader, Audio, and Standard decks directly from the side panel.
