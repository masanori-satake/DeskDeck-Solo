Core Principles

4大コアポリシー

🔒

Local Only

すべてのデータ・処理はChromebook内で完全ローカル完結。外部サーバーへの通信は一切行いません。

🛡️

Zero Tracking

ユーザー行動ログ、アナリティクス、広告追跡は完全ゼロ。プライバシーを最優先に保護します。

⚡

Pure JavaScript

Webpack/Viteなどのビルドツールや外部ライブラリを排除したPure Vanilla Web Stack。透明で安全なコードベース。

💾

Local Backup

デッキ構成や設定のバックアップ・復元はローカルJSONファイル経由で行い、クラウド非依存で管理可能です。

Problem & Solution

タブレットモードの課題と解決策

⚠️ タブレットモードの課題

小さなUIボタンと操作性の限界

Chromebookをキーボードから切り離してタブレットモードで使う際、Webアプリ特有の操作課題が発生します。

  • ❌ Web会議（Meet / Teams）のマイクミュートやカメラ切り替えボタンが小さく指でタップしづらい
  • ❌ 全画面で動画視聴中や別タブでの作業中に、音量微調整や一時停止のために画面を切り替える手間
  • ❌ タッチパネル操作で意図せず離脱ボタンを押してしまう誤操作のリスク
  • ❌ 電子書籍やドキュメント閲覧時の拡大・縮小やダークモード切り替えのメニュー階層の深さ
💡 DeskDeck-Soloの解決策

サイドパネルに常駐する大型タッチデッキ

ChromeのサイドパネルUIを活用し、タッチ操作に特化した外付け物理コントローラーの質感を再現。

  • ✅ 最小64px以上の超大型タッチターゲットと直感的なフィードバック（Pointer Events対応）
  • ✅ アクティブなWebページを邪魔せず、常時アクセス可能なサイドパネル専用UI
  • ✅ 誤操作を防ぐ保護カバー付きトグルスイッチ構造（離脱操作等の安全保護）
  • ✅ 用途に合わせてワンタッチで切替可能な5つのプリセットハードウェアデッキ

Installation

インストール方法

1. ソースコードの取得

リポジトリをクローンまたはZIPダウンロードして展開します。

2. Chrome拡張機能ページを開く

Chromeブラウザで chrome://extensions/ を開き、右上の「デベロッパーモード」をONにします。

3. パッケージ化されていない拡張機能を読み込む

「パッケージ化されていない拡張機能を読み込む」ボタンを押して `projects/app` ディレクトリを選択します。

4. サイドパネルを開く

Chromeのサイドパネルアイコンから「DeskDeck-Solo」を選択して操作を開始します。

FAQ

よくある質問 (FAQ)

Q: 外部サーバーやネットワーク通信は行われますか？

A: いいえ。DeskDeck-Soloは完全ローカル（Local-Only / Zero-Tracking）で動作し、一切のネットワーク通信を行いません。

Q: タブレットモード以外のPCでも使えますか？

A: はい。マウス操作やキーボードショートカットでの操作にも完全対応しています。

Q: デッキのカスタマイズやバックアップはできますか？

A: はい。オプション画面から各デッキのスロット設定を変更したり、JSONファイルとしてローカルへエクスポート/インポートできます。
