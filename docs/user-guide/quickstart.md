# DeskDeck-Solo クイックスタートガイド (Quickstart Guide)

DeskDeck-Solo のインストールから基本操作、おすすめの使い方を解説します。

## 1. インストール手順

1. **ソースコードの取得**:
   - リポジトリをクローンするか、[Releases](https://github.com/masanori-satake/DeskDeck-Solo/releases) より `DeskDeck-Solo-v0.1.1.zip` をダウンロードして解凍します。
2. **Chrome拡張機能ページを開く**:
   - Google Chrome または ChromeOS ブラウザで `chrome://extensions/` にアクセスします。
   - 画面右上の「デベロッパーモード」を ON にします。
3. **拡張機能の読み込み**:
   - 「パッケージ化されていない拡張機能を読み込む」ボタンをクリックし、`projects/app` ディレクトリを選択します。
4. **サイドパネルの起動**:
   - ブラウザ右上のサイドパネルアイコン（または拡張機能アイコン）をクリックし、「DeskDeck-Solo」を選択します。

## 2. 5つのデッキの使い方

### 🎵 Media Deck (メディアコントロール)

- **大型回転ノブ**: 指で円を描くようにドラッグして音量をスムーズに調整できます。
- **操作ボタン**: 再生/一時停止、曲送り/曲戻し、ワンタップ消音。

### 📹 Meeting Deck (Web会議)

- **マイク / カメラスイッチ**: 1タップでミュート/カメラ切替。
- **安全保護フリップスイッチ**: 会議離脱操作には、保護カバーを上スワイプして開けてからスイッチを操作する2重保護を採用しています。

### 📖 Reader Deck (ドキュメント閲覧)

- **ズームノブ**: ページ拡大率の変更。
- **トグル**: ダークモード切替、フォントサイズ変更。

### 🎧 Audio Deck (ミキサー)

- **縦型フェーダー**: 各チャンネルのボリュームを上下ドラッグでコントロール。

### 🖥️ Standard Deck (ブラウザ操作)

- **タブナビゲーション**: タブの切り替え、新規作成、閉じる操作を片手で快適に実施。

## 3. 設定・バックアップ (Options & Backup)

- デッキ上の設定ギアアイコン（または拡張機能のオプション）をクリックするとオプション画面が開きます。
- **ローカルバックアップ**: 設定やデッキカスタマイズ状態を JSON ファイルとして書き出し・復元できます。
