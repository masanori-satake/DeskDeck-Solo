Privacy Policy / プライバシーポリシー

Last updated / 最終更新日: 2026年5月

DeskDeck-Solo is designed with privacy and local security as top priorities.

1. Local-First & Zero Data Collection / 完全ローカル動作・データ収集なし

  • DeskDeck-Solo operates entirely locally on your device.
  • No user data, usage analytics, personal identifiers, browsing history, or deck configurations are ever collected or transmitted.

2. Chrome Storage API Usage

Settings are saved locally using Chrome's chrome.storage.local API.

3. Contact & Support

For questions, please open an issue on GitHub.
